## 🌐 Deploy on GitHub Pages

### Step 1:
Push your project to GitHub.

### Step 2:
Go to:

```bash
Settings → Pages
```

### Step 3:
Under **Branch**, select:

```bash
main
```

Then click **Save**.

### Step 4:
Your site will be live at:

```bash
https://yourusername.github.io/repository-name/
```
